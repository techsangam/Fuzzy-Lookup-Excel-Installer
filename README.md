# Fuzzy Lookup Add-In for Microsoft Excel 1.3.0.0

**Find approximate matches between data tables in Microsoft Excel.**

Fuzzy Lookup Add-In is a Microsoft Excel extension designed to identify approximate matches between text values in different tables. It helps users find similar names, identify spelling variations, and compare datasets efficiently.
